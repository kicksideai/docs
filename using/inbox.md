# Inbox

Open **Inbox** to review notices and work assigned to you. Installed item types determine each item's fields and actions.

Open an item, read its context, and use its available action. A review item can ask for approval or another decision. Submitting the response signals the waiting Flow; inspect that Flow's run state to confirm subsequent steps finish.

Inbox owns assignment and the review item. The Flow runtime owns its parked execution and recovery. A completed Inbox action does not grant the Flow access to resources its execution identity lacks.

See [automations and workflows](automations-and-workflows.md).
